# CyberRover (سايبر روفر)

**مركبة الفحص الأمني الذاتي والمسح اللاسلكي**
*Autonomous Wi-Fi Patrol & Security Inspector*

> «حيث تتوقف المراقبة الثابتة.. يتحرك سايبر روفر»

مشروع مشارك في **هاكاثون رواد التقنية**، فئة **الابتكارات التقنية والذكاء الاصطناعي**.

## الفكرة

روبوت ميداني ذاتي الحركة يساند فرق الدعم الفني والأمن السيبراني في المنشآت الكبيرة (الفنادق، المصانع، المجمعات الإدارية). يتجول في الممرات، ويتوقف عند نقاط فحص محددة بملصقات QR، ويقيس شبكة Wi-Fi **من منظور المستخدم**، ثم:

- يرسم **خريطة تغطية** ويكشف **النقاط العمياء**.
- يكشف **الشبكات الدخيلة والتوأم الشرير** (Rogue AP / Evil Twin) بمطابقة SSID و BSSID والقناة والتشفير مع القائمة البيضاء.
- ينبّه على **الشبكات المفتوحة أو ضعيفة التشفير**.
- يستخدم **الذكاء الاصطناعي (كشف الشذوذ)** ليتعلم البصمة الطبيعية لكل موقع ويرصد أي تغيّر غير معتاد.
- يرسل **تنبيهاً فورياً** للفني عبر Telegram.

## المشكلة

الفحص الميداني للشبكات اللاسلكية يستهلك وقت الفنيين، ولوحات التحكم المركزية ترى أجهزة البث فقط ولا ترى ما يعيشه المستخدم فعلياً في الممرات والغرف.

## آلية العمل

```
الحركة وتفادي العوائق  →  قراءة ملصق QR (تحديد الموقع)  →  توقف ومسح متعدد (متوسط RSSI)
→  مطابقة القائمة البيضاء + نموذج كشف الشذوذ  →  خريطة التغطية + تنبيه فوري للفني
```

## هيكل المستودع

| المجلد | المحتوى |
|---|---|
| `firmware/cyberrover_robot/` | برنامج ESP32 الرئيسي: الحركة، تفادي العوائق، المسح السلبي، فحص السياسة، تقرير JSON |
| `firmware/cyberrover_cam/` | برنامج ESP32-CAM: قراءة ملصقات QR وإرسالها للوحة الرئيسية |
| `ai/` | تسجيل البيانات من الروبوت، نموذج كشف الشذوذ (Isolation Forest)، تنبيهات Telegram |
| `dashboard/` | لوحة المراقبة (Streamlit) |
| `docs/` | العرض ثلاثي الأبعاد (GitHub Pages)، تقرير القطع، قائمة المواد |

## التشغيل السريع

**١. البرمجة المدمجة (Arduino IDE)**
- ثبّت حزمة ESP32 والمكتبات: `ESP32Servo`، `Adafruit SSD1306`، `Adafruit GFX`، `ESP32QRCodeReader`.
- عدّل `firmware/cyberrover_robot/whitelist.h` بنقاط الوصول الحقيقية للمنشأة.
- ارفع `cyberrover_robot.ino` إلى ESP32 و`cyberrover_cam.ino` إلى ESP32-CAM.

**٢. البيانات والذكاء الاصطناعي (Python 3.10+)**
```bash
pip install -r requirements.txt
cd ai
python anomaly_detection.py --demo          # تجربة النموذج ببيانات محاكاة
python serial_logger.py --port COM5         # تسجيل جولة حقيقية
python anomaly_detection.py --train data/baseline.jsonl
python anomaly_detection.py --check data/scans.jsonl
```

**٣. لوحة المراقبة**
```bash
streamlit run dashboard/app.py
```

للتنبيهات عبر Telegram، عرّف المتغيرين `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`.

## الإطار الأخلاقي

يعمل CyberRover **بالمسح السلبي (Passive Scanning)** فقط: يستمع لإشارات البث ولا يتصل بأي شبكة ولا يهاجمها، ويُستخدم **داخل نطاق المنشأة المصرّح بها فقط** وبموافقة إدارتها.

## القيود الحالية

- شريحة ESP32 تمسح نطاق **2.4GHz فقط**. لمسح 5GHz يمكن استبدالها بـ ESP32-C5.
- البيانات في وضع `--demo` وفي العرض ثلاثي الأبعاد **محاكاة** للتوضيح.
